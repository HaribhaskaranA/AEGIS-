AEGIS SAR // SYSTEM ARCHITECTURE & MULTI-AGENT PRINCIPLES

1. Decentralized Multi-Agent Search Principles

Each drone maintains an onboard probability belief map of the 25 km² disaster grid and plans trajectories along maximum entropy gradients without relying on a single point of failure.

2. Edge AI Thermal & Multi-Sensor Inference

Onboard Jetson Orin modules run SAR-YOLOv9-Edge-v3 and YOLOv8-Thermal-SAR v2.4 over radiometric FLIR LWIR imagery, syncing 512-dimensional feature vectors with a PostgreSQL / Supabase pgvector database containing 10,240 trained thermal signatures.

3. Ethical Human-in-the-Loop Casualty Verification

Automated sensor detections are treated strictly as probabilistic hypotheses. Ground rescue and medevac units are never dispatched without explicit human rescuer confirmation.
